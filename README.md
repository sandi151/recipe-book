# Мой рецептник

Десктопное приложение на Python и PyQt6 для хранения личных рецептов.

## Описание

Пользователь добавляет рецепты с фото, ингредиентами и категориями, ищет и фильтрует их, подбирает блюда по имеющимся дома продуктам, формирует список покупок и экспортирует данные в txt и csv.

**Цель:** создать удобный каталог рецептов, который заменит разрозненные заметки и закладки.

**Целевая аудитория:** люди, которые готовят дома и хотят держать свои рецепты в одном месте.

**Оригинальная идея:** функция «Что приготовить?» подбирает рецепты из базы по списку продуктов, которые есть у пользователя.

## Возможности

- добавление, просмотр, редактирование и удаление рецептов
- прикрепление фото блюда
- хранение категорий, ингредиентов и их количества
- поиск по названию и фильтры по категории и времени приготовления
- подбор рецептов по списку имеющихся продуктов
- список покупок с отметкой «куплено»
- таймер приготовления в карточке рецепта
- экспорт: список покупок в txt, рецепты в csv

## Технологии

- Python 3.10+
- PyQt6
- SQLite (модуль sqlite3)
- PyInstaller (сборка exe)

## Окна приложения

| Окно | Назначение |
|---|---|
| Главное | Таблица рецептов, поиск, фильтры, кнопки управления |
| Карточка рецепта | Фото, ингредиенты, шаги, порции, таймер |
| Форма рецепта | Добавление и редактирование |
| Список покупок | Чекбоксы, экспорт в txt |
| «Что приготовить?» | Ввод продуктов и подбор рецептов |

## База данных

- `categories` (id, name)
- `recipes` (id, title, category_id, cook_time, servings, steps, photo_path)
- `ingredients` (id, name)
- `recipe_ingredients` (recipe_id, ingredient_id, amount, unit)
- `shopping_list` (id, ingredient_id, amount, bought)

## Используемые элементы PyQt6

- **Виджеты:** QTableWidget, QLineEdit, QComboBox, QSpinBox, QTextEdit, QTabWidget, QCheckBox, QListWidget
- **Дополнительные виджеты:** QLCDNumber и QTimer (таймер), QSlider (фильтр по времени), QCalendarWidget (планирование меню)
- **Стандартные диалоги:** QFileDialog, QMessageBox, QInputDialog
